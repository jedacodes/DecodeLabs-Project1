# DecodeLabs AI Engineering Track - Project 1
## Module 01: Deterministic Chatbot Engine

### 📌 Project Overview
This repository contains the official milestone submission for Project 1 of the DecodeLabs Industrial Training Track. The objective of this project is to engineer a high-reliability, rule-based conversational control layer designed to handle structural query matching without relying on heavy non-deterministic layers.

### 📂 File Structure & Formats
* **`chatbot_engine.py`**: Core Python script housing the deterministic logic matching layer, processing functions, and localized state memory.
* **`README.md`**: Comprehensive architectural documentation and setup instructions.

### ⚙️ Key Requirements Met
* **Automated Keyword Ingestion**: Captures user input arrays and tokenizes string streams.
* **Fallback Resolution Paths**: Implements strict default safety protocols to handle unmapped edge cases gracefully.
* **Clean State Isolation**: Operates with complete logical compliance, isolating variables natively.
